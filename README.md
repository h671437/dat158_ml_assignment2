Wine Quality Predictor

A web app that predicts the quality (0-10) of a Vinho Verde wine from its chemical measurements, using a random forest model.

Demo video: https://youtu.be/6tBsMRz0HM4
Report: report.pdf
Notebook: notebooks/wine_quality.ipynb
Run the app
cd app
pip install -r requirements.txt
python app.py

Open http://127.0.0.1:7860

Data: UCI Wine Quality (Cortez et al., 2009). AI tool used: Claude (Anthropic)
